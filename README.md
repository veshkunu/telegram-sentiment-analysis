# Telegram Sentiment Analysis Bot

AI-powered Telegram chatbot for sentiment analysis using Python, Hugging Face Transformers, and Gemini AI.

## Features
- Sentiment analysis on text
- Telegram bot integration
- AI-generated responses
- Image analysis support

## Technologies Used
- Python
- Transformers
- Telegram Bot API
- Gemini AI
- Pillow

## Installation

1. Clone the repository

```bash
git clone https://github.com/veshkunu/telegram-sentiment-analysis.git
```

2. Install dependencies

```bash
pip install -r requirements.txt
```

3. Add your API keys in a `.env` file

4. Run the bot

```bash
python transformer.py
```
